# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions. Harassment, personal attacks and publishing other people's private information are not accepted.

Report a concern by opening a private security advisory on the repository, or by contacting the maintainer through their GitHub profile. Reports are read by the maintainer and handled confidentially.
